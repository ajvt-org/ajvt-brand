# Photo frames

Furniture to lay **over** a match photograph. Nothing is cropped, matted or
resized — the photo keeps every pixel it was shot with, and the frame goes on
top of it.

Each file is a PNG with a transparent middle. Only the hairline border, the two
marks, the names and a soft shading along the bottom are painted; everywhere
else the photograph shows through untouched.

Generated by `npm run build:frames`. Do not edit these files by hand — the next
build overwrites them, and `npm run build` deletes this whole folder before
rewriting it.

## Which file

Pick the one shaped like your photograph. This matters more than anything else
on this page: the wrong shape has to be stretched, and stretching is what makes
a frame look wrong.

| File | Shape | For |
| --- | --- | --- |
| `corner-photo.png` | 4:3 | A photo straight off a phone or camera, uncropped |
| `corner-square.png` | 1:1 | Facebook and Instagram feed, WhatsApp |
| `corner-portrait.png` | 4:5 | Instagram feed, tallest it allows |
| `corner-story.png` | 9:16 | Instagram and WhatsApp stories |

If your photograph is none of these shapes, crop the **photograph** to the
nearest one first, then apply the frame. Never crop the frame.

## How to use one

1. Open your photograph in any app that can put one image on top of another.
2. Add the frame PNG as a layer above it.
3. Drag its corners until it covers the photograph exactly — edge to edge, no
   margin showing, nothing hanging off. Hold Shift while dragging if the app
   offers it, so the proportions stay locked.
4. Export or save as usual.

The files are 2048–2160 pixels wide, so they scale **down** onto almost any
photograph without going soft. Avoid scaling them up much past their own size.

### In the apps people actually have

- **Canva** — Uploads → upload the PNG → drag it onto the photo → pull the
  corner handles out to the edges of the page.
- **Photoshop / GIMP / Photopea** — File → Place, then Free Transform out to the
  canvas edges.
- **Phone** — the Canva app works the same way as the desktop one. PicsArt can
  do it with "Add photo". Apps with no layers, like Snapseed, cannot.

## Please don't

- Recolour it, add a shadow or an outline to it, or change its opacity.
- Move the marks, resize one of them on its own, or retype the names.
- Stretch it to a shape it was not made for.

Every one of those is a change to the association's mark, and all of them are
avoidable: if a shape or a language is missing, it is one line in
`templates/social/frames/corner/frame.json` and a rebuild.

## What is on it

Everything comes from `brand/entities.yml`, not from anything typed per match —
which is why nothing on the frame can be edited, and why the competition cannot
go out misspelled.

- **Top left** — the cup's own mark, in colour, no ground behind it.
- **Top right** — the association's roundel. Its mint disc is part of the
  drawing, not a plate.
- **Bottom left** — كأس عمدة التاكلالت, and the season under it.
- **Bottom right** — رابطة شباب التاكلالت, the association's endorsement line.

### One thing to watch

In colour, the cup's chalice is drawn in `mint.900`, which is nearly black. On a
very dark photograph it goes quiet and only the gold crown reads clearly. If
that turns out to matter on real match photos, the fix is a one-ink variant of
that corner — ask, and it becomes a second file here.
